今回私が作ったのは、訪日外国人消費動向分析アプリというのを作りました。
このアプリのデータは、政府統計ポータルサイト「e-Stat」のデータから観光庁のサイトから使用しています。
=============未使用UIの説明について===================
1.st.metric
使用箇所: アプリ上部の平均単価表示に使用
目的: 重要な平均単価数字を大きく目立たせるために使用し、最初に目がつく場所に設定した。
2.st.tabs
使用箇所: グラフ、地図、データの表示切り替え
目的: 画面を縦に伸ばさず、だれが見ても見やすいように情報を整理して表示した。
3.st.progress
使用箇所: 詳細データタブの消費レベルメーター
目的: 各国の消費額がMAXに対してどれくらいかを視覚的に表現するために使用した。
4.st.expander
使用箇所: 元データの表示エリア
目的: 元データは見てもわからないことがあるので普段は隠しておき、統計や表を見るなど必要な時だけ見れるようにするために表示した。これによって図だけの構成にして、見やすくした。
5.st.map
使用箇所: 地図タブ
目的: どこの国からの観光客かを地図上で確認できるようにするために使用した。これは、もっと各国から観光客が来てどこの州から多く来ているのかを一目でわかるようにした。
